# French with G — Version 2

A private, free Progressive Web App for daily French speaking practice.

## New in V2
- 90-day structured learning path
- Daily 20-minute session
- Personal conversation coach with real-life scenarios
- Speaking lab with French speech recognition where supported
- Phrase-match feedback
- Smart review that prioritizes less-reviewed vocabulary
- Local streak/progress tracking
- Adjustable 10/20/30-minute daily goal
- Offline app shell
- No login, subscription, or API key

## Install on Android
Serve this folder over HTTPS (for example with GitHub Pages), open the HTTPS address in Chrome on Android, then use Chrome's "Add to Home screen" / install option.

## Privacy
Core app data is kept in the browser's local storage. Speech recognition is provided by the browser/device when available; this app does not save audio recordings.

## V2 limitation
The "AI coach" is a structured conversation coach rather than a cloud AI model. This keeps V2 free. A future V3 can add optional AI conversation using an API if desired.
